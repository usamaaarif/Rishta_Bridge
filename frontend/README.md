# RishtaBridge Frontend

This is the React-based frontend for the RishtaBridge application.

## 🎨 Design System
- **Framework**: React (Vite)
- **Styling**: TailwindCSS
- **Theme**: "Emerald & Gold" (Premium/Islamic aesthetic)
- **Icons**: Lucide React

## 📂 Structure
- `/src/components`: Reusable UI components (Buttons, Inputs, Layout).
- `/src/pages`: Main views (Home, Register, Search, Biodata).
- `/src/lib`: Utilities (Tailwind class merger).

## 🚀 Commands

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Lint
```bash
npm run lint
```
